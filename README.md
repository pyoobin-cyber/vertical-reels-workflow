# 세로릴스 제작 워크플로

다빈치 리졸브와 애프터 이펙트로 세로 영상을 정리·편집하는 한국어 AI 스킬입니다. 촬영 정리부터 모션 자막, 합성·출력까지 요청한 단계에 적용합니다.

**원본은 자르지 않고 전체 길이로 보존하면서 콘티·스토리보드 흐름에 맞춰 배열합니다.** 싱크가 맞는 영상·음향은 함께 이동하고, 사용할 구간은 클립 내부 OK 마커로 표시합니다.

[공유용 ZIP 다운로드](https://github.com/pyoobin-cyber/vertical-reels-workflow/releases/latest/download/vertical-reels-workflow-v1.0.zip) · [설치·사용 안내](시작하기.md) · [스킬 전문](vertical-reels-workflow/SKILL.md)

## 포함된 작업 기준

- 대상 영상의 원본을 각각 한 번씩, 전체 길이로 보존
- 탑·사이드 두 앵글의 싱크 유지와 콘티 중심 배열
- 실제 화면 검수에 근거한 클립 내부 OK 표시
- 클립별 세로 구도와 색보정
- **색보정 노드를 하나 추가해 하이라이트·섀도우 디테일 정리**
- 현재 편집 상태와 사용자가 삭제·수정한 결과 존중
- 에펙 모션 자막 수정, 컷 변경에 따른 타이밍 갱신, 투명 출력·합성

특정 브랜드·개인 경로·기존 프로젝트에 의존하지 않습니다. 해상도·프레임레이트·색공간은 사용자 지시와 프로젝트 설정을 우선하며, 내레이션 제공자나 카메라 LUT를 고정하지 않습니다.

## 사용 방법

1. 위 ZIP을 다운로드하고 압축을 풉니다.
2. `vertical-reels-workflow` 폴더 전체를 사용 중인 에이전트의 스킬 폴더에 설치합니다. Codex에는 해당 폴더를 지정해 “이 스킬을 개인 스킬로 설치해줘”라고 요청할 수 있습니다.
3. 촬영 폴더·콘티·작업 폴더 또는 현재 프로젝트와 수정 지시를 전달합니다.

예시:

> $vertical-reels-workflow로 촬영 정리해줘. 첨부한 A/B 폴더에서 대상 영상의 원본만 골라 전체 길이로 보존하고, 싱크를 유지하며 콘티 순서로 배열해줘. OK 표시, 세로 구도, 추가 노드의 하이라이트·섀도우 보정까지 진행해줘.

기존 동명 스킬이 있으면 내용을 비교하거나 백업한 뒤 설치합니다. 자세한 규격 설정과 자막 수정 예시는 [시작하기](시작하기.md)를 참고하세요.

## 실행 환경과 검증 범위

이 저장소는 에이전트의 작업 지침을 제공합니다. 실제 편집에는 요청한 단계에 필요한 Resolve·After Effects, 미디어 접근, 앱 제어 또는 스크립트 실행 연결이 필요합니다. 편집 앱·자동 실행 엔진·AEP 템플릿·LUT·폰트·원본 미디어는 포함하지 않습니다.

스킬 형식, 문서 연결, 개인 프로젝트 정보 제거, 배포 ZIP의 무결성을 확인했습니다. 모든 운영체제와 앱 버전에서 자동 편집 실행을 검증한 패키지는 아니며, 작업 시 실제 적용 결과를 확인하도록 지침에 명시했습니다.
