# 모션 자막과 최종 전달

## 시작 자료

현재 편집 타임라인의 버전, 컷 변경 내용, 최신 승인 AEP 또는 자막 디자인, 문구, 폰트·로고 등 필요한 자산을 확인한다. 기존 자막 수정은 최신 승인본을 기준으로 새 버전에서 진행한다. 과거 스크립트로 사용자가 수정·삭제한 레이어나 효과를 되살리지 않는다.

이 공유본에는 특정 AEP·폰트·로고·음악·LUT가 포함돼 있지 않다. 템플릿이 없고 새 자막 제작도 요청됐다면 제공된 디자인 지시에서 제작한다. 기존 자막 수정 요청인데 AEP가 없다면 편집 연결 기록 등 가능한 준비를 진행하고 필요한 파일을 확인한다. 존재하지 않는 템플릿을 재사용했다고 말하지 않는다.

## 컷과 자막 연결

각 자막을 절대 시간뿐 아니라 **어느 컷의 어느 원본 동작에 붙는지** 기록한다. 에이전트가 다음 항목을 관리한다.

| 항목 | 내용 |
| --- | --- |
| 식별 | 자막 ID, 문구, 모션 유형, 연결된 편집·AEP 버전 |
| 컷 | 컷 ID, 원본 클립 ID, 사용한 소스 구간 |
| 시간 | 타임라인 시작점, 컷 내부 자막 시작·끝, 기준 동작 프레임, 정확한 fps |
| 배치 | 위치·크기, 원형·곡선 반경, 회전, 가림에 필요한 기준 물체 |
| 검수 | 문구·가독성·모션·마스크 확인 결과와 미확인 항목 |

시간은 각 기준의 fps와 시작 포함·끝 제외 여부를 명시해 관리한다. 소스 프레임, 타임라인 프레임, 타임코드 표시를 혼용하지 않는다. 같은 소스를 여러 번 쓰는 편집본에서는 각 사용 구간에 다른 컷 ID를 부여한다.

속도 변화가 없는 컷은 타임라인의 컷 시작에 컷 내부 오프셋을 더해 자막 시작을 계산할 수 있다. 앞부분 트림이나 속도 변경이 있으면 원본 기준 동작과 타임라인 대응을 다시 확인한다.

## 컷 변경 반영

| 변경 | 처리 |
| --- | --- |
| 컷 위치 이동 | 같은 컷인지 확인하고 자막·키프레임·마스크 시간을 같은 양만큼 이동 |
| 컷 앞뒤 길이 변경 | 기준 동작이 남는지 확인하고 등장·퇴장과 모션 완결성을 조정 |
| 삭제·교체·분할·속도 변경 | 영향받은 자막을 검수 대기로 두고 연결 관계를 다시 설정 |
| 영상 확대·위치·회전 변경 | 자막 중심·반경·가림 경계를 실제 화면에 맞춰 재검수 |
| 문구 변경 | 줄바꿈·원형 글자 간격·등장 속도·읽을 수 있는 시간을 확인 |

전체 자막을 일괄 비례 압축하는 방식으로 컷 변경을 처리하지 않는다. 실제 동작과 읽는 시간을 기준으로 조정한다.

## 에펙 작업

1. 최신 AEP와 의존 미디어·폰트가 연결되는지 확인하고 새 버전으로 저장한다. 다른 사용자가 같은 프로젝트를 편집 중이면 겹쳐 쓰지 않는다.
2. 사용자 디자인에 맞는 기존 모션을 재사용한다. 예를 들어 글자별 등장, 원형·곡선 배치, 물체 회전 연동, 가림 효과를 쓸 수 있지만 모든 영상에 강제로 적용하지 않는다.
3. 문구, 위치, 크기, 반경, 등장 속도와 표시 길이를 장면별로 조정한다. 마스크·트래킹은 해당 촬영의 실제 물체에 맞춰 확인한다.
4. 현재 제공되는 앱 제어 기능으로 적용한다. JSX 등 스크립트를 만들 경우 대상 컴포지션·레이어·의존 경로와 변경 내용을 확인한 뒤 실행한다.
5. 앱에서 읽기 쉬운지, 모션과 실제 동작이 맞는지, 가림 경계가 자연스러운지 검수한다. 미리보기 영상은 필요하거나 요청된 경우에만 출력한다.

이 기록을 작성하거나 AEP를 저장했다는 사실만으로 컷 변경 감지·자막 갱신·렌더가 자동화됐다고 말하지 않는다. 실제 실행 수단과 결과를 확인한다.

## 투명 출력과 다빈치 합성

- 자막 전용 출력에 배경 영상이 포함되지 않도록 확인한다. 대상 환경이 지원하는 알파 포함 코덱으로 출력한다. 예: ProRes 4444 MOV.
- 해상도·정확한 fps·출력 구간·기준 시작 프레임을 편집본과 맞춘다. 투명도와 색 해석은 실제 합성 결과로 확인한다.
- 해당 편집본의 새 버전에 전용 상단 자막 트랙을 확보해 배치한다. 고정 트랙 번호를 가정해 기존 영상을 덮어쓰지 않는다.
- 흰 글자·브랜드 색·알파 가장자리, 검은 배경 유무, 자막 누락·중복, 컷 전환 프레임을 확인한다. 자막에는 카메라 로그 LUT를 적용하지 않는다.
- 전체 길이 자막 MOV는 편집 컷이 바뀌면 관련 AEP 타이밍을 갱신하고 필요 시 다시 출력한다. 영상만 움직여 에펙 모션이 자동으로 따라온다고 가정하지 않는다.

## 음향·내레이션·최종 출력

영상 원음·효과음·음악·내레이션은 필요한 범위에서 개별 수정 가능한 트랙을 유지한다. 음량·동작 시점·음악 연결을 실제로 듣고 확인한다. 내레이션은 사용자가 제공하거나 지정한 서비스·파일을 사용하며 특정 제공자를 고정하지 않는다. 기존 음성 설정은 확인 후 재사용한다.

최종 출력까지 요청된 경우 납품 규격에 맞춰 렌더한다. 파일 존재·메타데이터·길이·디코딩 상태를 확인하고 화면과 소리로 검수한다. 확인하지 않은 전체 구간을 모두 검수했다고 보고하지 않는다.

DRP·AEP·투명 자막·최종 영상·작업 기록을 편집 버전과 연결해 전달한다. 의존 자산과 미디어 경로, 남은 항목을 포함하되 개인용 음성·폰트·원본 등이 파일 하나에 자동 포함된다고 설명하지 않는다.
